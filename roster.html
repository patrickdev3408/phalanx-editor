How many characters start in each class, so holes and pile-ups in the roster are easy to spot. Every character starts with two classes (1st and 2nd starting class, from each character's starting classes in Supabase; set them in the web editor, then reload). Since 2026-10-04 minions have two real classes too (they use only the Actions); toggle a tier to include or exclude it.

Characters per class, grouped by playstyle. The dashed line is the average class; a red count means fewer than half the average (a hole). Click a class name to list its characters.
